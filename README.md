# SiteCanvas

SiteCanvasは、ブラウザ上で文字や画像を自由に配置し、Webページを作れるエディターです。アカウント登録やビルドは不要です。

## 使い方

1. 4つのファイルを同じフォルダーに置き、PCのブラウザで `index.html` を開きます。
2. サンプルを編集するか、「新規作成」で白紙から始めます。左側のパネルでテキスト、画像、ボタン、四角形、ヘッダー、フッターを追加できます。
3. キャンバス上の要素をドラッグして移動します。角のつまみでサイズを変え、右側のパネルで色や文字などを調整できます。
4. 「PC」「スマホ」を切り替えて、それぞれの配置を整えます。「プレビュー」で完成時の見た目を確認できます。
5. 「HTMLを書き出す」を押すと、CSSと画像を含むHTMLファイル1枚が保存されます。「ファイルを開く」から、SiteCanvasで書き出したHTMLを再編集できます。

## コードと要素のスタイルを編集する

- キャンバスで要素を選ぶと、右の設定で幅・高さ、`padding`（内側の余白）、`margin`（外側の余白）を指定できます。レイヤー編集では「PC」「スマホ」それぞれの値をピクセルで設定できます。
- 「ヘッダー」「フッター」はページの上端・下端に追加されます。ほかの要素と同様に、右の設定で表示する文字や背景色、位置とサイズを変更できます。ページの下端にあるフッターは、ページの高さを変えても下端に移動します。
- キャンバス上部の「コード」を押すと、ページのHTMLとCSSを閲覧・編集できます。「コードを反映」を押すと、キャンバスと書き出すHTMLに変更が反映されます。「元に戻す」で反映前のレイヤー編集に戻れます。
- コードを反映したあとや既存のHTMLを開いたときは、キャンバスまたは左の「HTML 要素」一覧からタグを選べます。右のボックスモデルでは `24px`、`2rem`、`50%` などのCSS値を指定できます。変更はそのタグの `style` に反映されます。キャンバスとプレビューではJavaScriptの実行を無効にしています。
- キャンバス上部の「要素検査」を押すと、要素にカーソルを合わせて表示サイズや余白を調べられます。クリックで選択し、右のCSSインスペクターで `position: absolute`、`top`、`left`、`z-index`、Flex、Gridなどを設定できます。一覧にない指定は「任意の CSS プロパティ」に入力できます。入力は Enter またはフォーカスを外すと反映され、空欄にすると指定を解除できます。
- レイヤー編集から要素検査を開いた場合は、CSSを初めて適用した時点でHTMLタグ編集に切り替わります。適用を元に戻すとレイヤー編集に戻ります。

## ファイルの階層と自動保存

- 左の「ファイル」では、編集対象のHTML、埋め込みのCSSやデータ、HTMLから参照しているファイルを確認できます。参照先はフォルダーごとに表示されます。HTMLのファイル名を押すとコードを開けます。
- 変更は1分ごとと、リロードやページを離れるときに、同じブラウザのローカルストレージへ保存されます。コード欄の未反映の下書きも復元されます。キャンバス上部に保存状況と最終保存時刻を表示します。

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | エディター画面 |
| `style.css` | エディター画面のスタイル |
| `script.js` | 編集、プレビュー、HTMLの書き出しと読み込み |
| `README.md` | 使い方と公開手順 |

## GitHub Pagesでエディターを公開

1. この4つのファイルをGitHubリポジトリのルートにアップロードします。
2. リポジトリの **Settings → Pages** を開きます。
3. **Build and deployment** の **Source** に **Deploy from a branch** を選びます。
4. ファイルを置いたブランチ（例 `main`）と **/(root)** を選択し、**Save** を押します。
5. 公開後、**Settings → Pages** に表示されるURLからエディターを開きます。

[GitHub Pagesの公開元を設定する手順](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

SiteCanvasで作ったページは、別のリポジトリや公開フォルダーに置けます。書き出したHTMLをその公開先の `index.html` にすると、そのページがトップに表示されます。
